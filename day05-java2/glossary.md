# Claude Code用語

* [Claud Code]　エージェント型AIコーディングツール。機能を実装、テスト作成、PR作成まで自律的に対応してくれる。ターミナルで実行。
* [プロンプト]　AIに命令するための質問文のこと。
* [コンテキスト]　AIが参照できる情報の範囲のこと。
* [CLAUDE.md]　Cloud Codeがセッション開始時に読み込む設定ファイルのこと。
* [権限（許可）]　ファイル編集やコマンド実行を、実行前に確認承認する仕組み
* [MCP]　AIモデルや、AIエージェントが外部のツール等に接続するための共通規格のこと。
* [サブエージェント]　メインとなるAIエージェントから特定の作業を専任され独立した環境で処理を行う    AIエージェントのこと。

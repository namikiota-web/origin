# Git手順メモ

* Githubにoriginリポジトリを新規作成する
* [git remote add origin URL]コマンド実行し、リモートのpush先リポジトリを登録
* [git switch feature/profile]コマンドを実行し、ローカルのブランチを作成し切り替える
* 変更したファイルを[git add .],[git commit -m "コミットメッセージ"]で変更をコミットする
* [git push -u origin ブランチ名]コマンドを実行し、リモートリポジトリ（origin）へプッシュする
* PR作成されているため、説明を記載する
* PRをレビューしてもらい、リモートにマージしてもらう。
